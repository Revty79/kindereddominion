# Source artwork masters

Original source artwork is committed here separately from optimized production assets in `public/assets/`. Each official imported revision records its source checksum and immutable source filename in the asset manifest. Never overwrite a source master or published optimized revision; publish a new revision instead.

`validation/sprout-study.svg` is an original temporary geometric test illustration for V1.2 packaging acceptance, not final commercial artwork. `scripts/create-test-artwork.mjs` renders the PNG used in browser upload tests. No card statistics, labels, borders or influence diagrams are part of the illustration.

After a publishing ZIP is validated and imported, commit the content JSON, source masters, optimized artwork and `public/assets/manifest.json` together. Browser-only experimental artwork is preserved by Studio backups until explicitly approved and packaged.
