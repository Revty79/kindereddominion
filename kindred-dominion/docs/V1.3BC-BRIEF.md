### 4. Card Definition Conventions

The following tables are the authoritative design input for this stage.

Placement types:

- I: Standard Rank I.
- II: Standard Rank II.
- III: Standard Rank III.
- R: Replacement.
- Evo: Evolution.

Influence notation:

- E: Expansion and placement-token contribution.
- G: Fortification.
- O: Overthrow.
- F: Forward.
- B: Backward.
- U: Up.
- D: Down.
- S: Self.
- FU: Forward-up diagonal.
- FD: Forward-down diagonal.
- F2: Two positions forward.
- ×2 or ×3: Influence strength.

Direction must mirror correctly for the opposing player.

Unless otherwise specified:

- Every influence contribution has strength one.
- Adjacent means orthogonally adjacent, not diagonal.
- Power modifications are permanent for the match unless described as continuous or dynamic.
- Triggered abilities have a maximum of one activation per event and per match, except where explicit repeatable behavior is specified.
- Persistent activation and lineage safeguards apply.
- Replacement requires a friendly creature.
- Evolution requires its listed predecessor.
- All ordinary targeting, protection and territory rules remain enforced.
- Standard copy limit is two.
- Field Mouse has a provisional three-copy override.
- Free Play allows up to 15 copies while retaining universal safeguards.
- Replacement and evolution rank metadata should correspond to intended progression difficulty without imposing additional placement-token requirements.

Implement precise classifications and tags to support the specified creature interactions.

Use the actual supported mechanics registry. Do not create descriptions for effects the engine cannot execute.

If a supplied ability cannot be represented accurately, identify the discrepancy and implement the closest valid testable interpretation only if it preserves the design intent. Document it explicitly. Do not silently omit effects or invent new major mechanics.

Cross-Kindred combinations should be attractive without making pure collections obsolete.

### 13. Gameplay Readability

The owner has reported that the current game is difficult to follow and that important information is difficult to locate.

Improve presentation without simplifying the underlying gameplay rules.

The player should immediately understand:

- Which cards can currently be played.
- Where each card can be placed.
- Which positions the card influences.
- Which positions gain placement tokens.
- Which positions gain fortification.
- Which enemy positions are captured.
- Which creatures are enhanced or weakened.
- Which creatures may be destroyed.
- How the action affects the score.

Provide a consistent visual language for:

- Placement tokens.
- Expansion.
- Fortification.
- Overthrow.
- Enhancement.
- Weakening.
- Destruction.
- Replacement.
- Evolution.
- Resurrection.
- Protection.
- Continuous effects.
- Scoring bonuses.

Use distinct shapes, symbols and explanatory labels rather than relying exclusively on colors.

### 14. Battlefield Presentation

Prioritize a clean, readable battlefield.

Requirements:

- Both players' row power must remain clearly visible.
- Show which player currently wins each row.
- Domination creature counts remain visible beneath the appropriate columns.
- Distinguish raw row power from awarded points.
- Display card-specific score bonuses separately.
- Display total current scores prominently.
- Show underlying territory ownership, tokens and fortification.
- Allow easy inspection of any battlefield creature.
- Clearly distinguish printed power from current effective power.
