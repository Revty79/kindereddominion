## Defects found and corrected during implementation

The first expiry query had an unmatched SQL parenthesis, caught by a real PostgreSQL expiration test. The corrected common predicate retains ambiguous provider attempts until verified terminal state. Tests then exercised delayed paid delivery, duplicate event settlement and release of verified expired/never-requested holds.

A cosmetic license test exposed that converting a limited projection attempted to overwrite immutable original acquisition fields. Current projection publication references are now separate. The ordinary acquisition receipt becomes current while the original provenance remains immutable; retiring the limited instance preserves an independent ordinary license. The reciprocal regression verifies that a new limited license works after an ordinary refund without resurrecting the revoked grant. Store eligibility uses the same active license identities to prevent charging again for an already owned ordinary appearance. Forward migrations preserve the existing immutable guard and add only the new operational projection fields to its allow-list.

Publication also now treats cosmetic-only products as having no gameplay pool: their exact cosmetic edition binding validates correctly, and an exclusive gameplay card does not block unrelated cosmetic products.

The browser exposed an ambiguous native select label; explicit accessible labels now identify the edition controls. Visual review also exposed flex sizing that made an instance portrait too small. The gallery now gives the shared 3:4 card an explicit readable width, and collection navigation includes a direct jump to limited collectibles. The new browser case asserts both minimum portrait width and preserved proportions.

Fixture-only failures were corrected without weakening application safeguards: long generated usernames now fit the existing account contract, binary artwork responses are inspected as artwork, administrator tests use separate isolated accounts rather than bypassing rate limits, and a sold-out product dialog is closed before subsequent navigation. Repeated-suite expansion fixtures now publish an honest greater definition revision when prior immutable history requires it, and the bounded pause-maintenance fixture explicitly places its declared order first in the private work queue. A legacy browser check initially inherited temporary starting-artwork configuration from the limited demonstration; a fresh target and neutral teardown keep those journeys isolated. No existing assertion, approval requirement or validation test was removed.

## Commercial and owner boundaries

Provider simulation is deterministic and runs against actual PostgreSQL. It is not genuine Stripe payment acceptance. Previous H.7-8 genuine sandbox receipts remain documented in the main report; they do not claim validation of a new real limited product. Genuine sandbox Hosted Checkout/webhook/retry/refund acceptance for owner-approved limited products remains an owner task before commercial activation. Live payment processing remains disabled.

Limited purchase fingerprints now include nonvolatile edition rights; stock counts remain informational. The edition row is locked through final wallet confirmation. Original provenance records the effective acquisition binding, so later trading enablement cannot free an originally bound cosmetic. An ambiguous provider response also remains held across a commerce pause until the original session is recovered or independently verified closed.

The terminal retirement policy is proposed for owner review. It prevents serial recycling and automatic resurrection even if a previously successful refund later fails. Unsupported future effects, physical redemption/NFC, cash player transfers, withdrawals and auctions remain unavailable. No actual limited edition or new gameplay expansion was published outside disposable fixtures.

Screenshots, traces, dumps and row hashes stay in ignored local evidence directories. The concise report is committed; player data, private assets and credentials are not. An accidentally overlapping pair of runners against one disposable target was discarded and rerun sequentially; it is not acceptance evidence.
