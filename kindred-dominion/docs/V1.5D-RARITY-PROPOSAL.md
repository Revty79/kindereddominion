# Provisional founding rarity proposal

DEV review proposal, not an approved permanent commercial policy. Official executable card definitions and their existing metadata are unchanged. No rarity modifies combat values. Every founding first copy remains available through ordinary Gold; first-copy packs include rare forms without a premium gate.

Each Kindred has 12 Common, 8 Uncommon, 5 Rare, 3 Epic and 2 Legendary cards. The explicit assignments are configurable and include tactical low-power specialists; printed power is not the sorting algorithm. Rationale below identifies each card's actual placement/ability role; owner review may revise these economic classifications without changing permanent card IDs.
