These results flag review candidates under the current one-ply AI. They do not establish human competitive balance, and no automatic rebalance occurred. ## Reproduce the clean-checkout checks

In a new directory, using a destination that does not already exist:

```powershell
git clone https://github.com/Revty79/kindereddominion.git D:\kindred-clean
cd D:\kindred-clean\kindred-dominion
npm ci
node scripts/validate-assets.mjs --tracked
npm test
npm run build
npx playwright install chromium
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5174 --strictPort
```

Keep that preview terminal open. In a second terminal, from the same application directory:

```powershell
$env:KINDRED_CLEAN_URL = 'http://127.0.0.1:5174/'
node node_modules/@playwright/test/cli.js test
Remove-Item Env:\KINDRED_CLEAN_URL
```

The suite starts its separate development server on port 5173 and uses port 5174 for the clean production check. Stop existing listeners before reproducing. Without `KINDRED_CLEAN_URL`, the ordinary suite intentionally skips only the separate clean-production test. Stop the preview with Ctrl+C afterward.

For morning testing, use the [owner guide](V1.2-OWNER-GUIDE.md) or the quick steps in [README](../README.md). V1.1 remains available, all new cards remain provisional, temporary artwork is testing-only, and final commercial illustrations remain reserved for V1.3.
