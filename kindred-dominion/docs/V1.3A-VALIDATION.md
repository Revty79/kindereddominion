## Compatibility, limits and review boundary

- Legacy libraries remain schema 1 / engine 1.1.0. Advanced content explicitly uses schema 2 / engine 1.3.0; only the edited working draft upgrades. Immutable old versions and recorded matches remain unchanged. Mixed backups declare the newest required engine and are validated atomically.
- Continuous qualification uses intrinsic power; scaling uses pre-dynamic power/classification. Final-power circular dependencies and pure random queries are rejected. This deliberate acyclic model is documented for card design.
- Captured values survive removal; creature effects using departure/incoming context require that exact instance to be live. An old net-only modifier cannot reconstruct unrecorded enhancement/weakening history.
- Numeric expressions/conditions have eight-level nesting and 100,000 power/intermediate bounds; history, generation, resolution and resurrection also have explicit ceilings. Invalid or over-budget advanced resolution halts with diagnostics and no result.
- Physical mobile, owner usability/artistic acceptance and expert/commercial balance are not claimed. The current computer policy is unchanged.
- Interactive target prompts, arbitrary scripts, a general timed-status system, recursive aura equilibria, additional full tactical rulesets, advanced AI, online services and mobile platform projects remain unsupported/deferred. See the master's full unsupported list.
- The 45 laboratory cards and all temporary images remain development fixtures. No final 150-card collection, commercial artwork, automatic rebalance, hosting/deployment or V1.3B redesign was created.
